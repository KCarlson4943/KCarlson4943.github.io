# Organizer.github.io
A work tracker that can help me and you stay on top of our busy lives. There will be a check list that you can add and remove items from as well as features to make it easy and fun to use.
Later I would like to add a calendar function as well. 

## Build proccess
I built this site carefully by adding and removing features until I had a raddicly simple site that does the heavy lifting. Instead of having a fun website where people want to spend time I made a website that is cool but keeps you on task so that you don't get distracted.
